# CBPay API 文档

在拉美范围内转移资金：payouts、payins、卡、加密货币和银行服务——一个 API，六个余额。

## 开始集成

- **快速入门** - 五分钟完成第一次 API 调用：密钥、沙盒和一笔测试 payout。
- **身份验证** - API 密钥、权限范围与请求签名。
- **沙盒与测试** - 测试模式、魔法值与模拟通道。
- **资金模型** - 六个独立余额及其之间的资金流转。
## 构建产品

- **法币 payouts** - 向该地区的本地银行账户汇款。
- **法币 payins** - 以当地货币收款并自动入账。
- **Checkout** - 一个支付链接；付款人选择国家、方式或加密货币。
- **卡** - 发行实时从任意余额扣款的卡。
- **链上加密货币** - 通过 TRON、Ethereum 和 Bitcoin 充值与提现。
- **Swaps** - 按账户汇率即时转换余额。
- **内部转账** - 即时免费地向任何 CBPay 账户转账。
- **Banking** - 以你名义开立的真实银行账户，走国际通道。
## 对账

- **对账单** - JSON、PDF 和 Excel 格式的账户对账单。
- **凭证** - 每笔操作的可验证签名凭证。
- **公开跟踪** - 可分享的交易实时状态页。
- **数据分析** - 为你的仪表盘提供交易量、计数与维度。
## 运营与参考

- **Webhooks** - 推送到你系统的事件，已签名且可重放。
- **实时事件** - 订阅实时事件流。
- **错误码** - 每个错误码及其解决方法。
- **常见问题** - 集成者最常问的问题。
- **Postman** - 覆盖各表面的现成集合。
- **文档 MCP** - 让 AI 助手替你查询这些文档。
- **服务状态** - 每条走廊与通道的实时健康状况。
